# TILT-FM web installer

GitHub Pages for [TILT-FM](https://github.com/CDMGaming/TILT-FM), custom firmware for the M-VAVE FM-1 and a fork of
[Felucca](https://github.com/hugelton/Felucca) (GPL-3.0-only, Leo Kuroshita, Hügelton Instruments).

- [webapp/installer/](https://cdmgaming.github.io/TILT-FM/webapp/installer/): TILT-FM 0.2.1, the tested release
- [next/webapp/installer/](https://cdmgaming.github.io/TILT-FM/next/webapp/installer/): a preview build, not yet
  tested on a real FM-1

Made with `web/make_tfm_site.py` (Felucca's `web/make_site.py`, then TILT-FM's name on the page).
